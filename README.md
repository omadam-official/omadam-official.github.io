# OMADAM Official Website

Official public website source for the OMADAM Universe.

## Structure
- `index.html` — homepage
- `styles.css` — responsive visual system
- `script.js` — small progressive-enhancement script
- `.nojekyll` — serve static files directly with GitHub Pages

## GitHub Pages
For the organization root URL `https://omadam-official.github.io/`, rename this repository to:

`omadam-official.github.io`

Then enable GitHub Pages from the `main` branch / root directory.

## Security
This is a public repository. Never commit API keys, credentials, internal IP addresses, secrets, or private operational data.
